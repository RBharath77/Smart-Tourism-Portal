## 🌎 AI-Powered Smart Tourism & Travel Recommendation Platform

A modern tourism management platform that helps travelers discover destinations, explore attractions, and receive intelligent travel recommendations through a responsive web application built with **Python (Flask)**.

---

# 📖 Project Overview

The **Smart Tourism Portal** simplifies travel planning by bringing destination information, travel recommendations, and tourism management into one platform.

The application demonstrates modern full-stack web development concepts using Flask, SQLite, HTML, CSS, and JavaScript while providing a user-friendly interface for exploring tourist destinations.

---

# ❗ Problem Statement

Travelers often face several challenges:

* Searching across multiple websites
* Lack of personalized recommendations
* Time-consuming trip planning
* Limited destination information
* Poor user experience

These issues make travel planning more difficult and less efficient.

---

# 💡 Proposed Solution

The Smart Tourism Portal provides:

* Destination search
* Tourist place information
* AI-assisted travel recommendations
* Responsive web interface
* Easy navigation
* Cloud deployment support

# 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/RBharath77/Smart-Tourism-Portal.git
```

### Navigate

```bash
cd Smart-Tourism-Portal
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate

**Windows**

```bash
venv\Scripts\activate
```

**macOS / Linux**

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run

```bash
python app.py
```

Open:

```text
http://127.0.0.1:5000
```
